# SEO audit — 2026-08-03

Follows `audit-2026-07-30.md`. That audit fixed the technical foundations
(canonicals, hreflang, JSON-LD, Open Graph, internal linking) and left three
items open. This pass closes the largest of them and quantifies the rest.

Method: the site's own registry is parsed directly rather than crawled page by
page, and every rendered claim (schema, canonical, hreflang, alt text) is
verified in a real browser — `curl` and fetch-based tools strip `<script>` tags
and cannot see JSON-LD, so a schema finding taken from them would be false.

---

## 1. URL parity and the 301 map — **closed, and better than expected**

This was recorded as *"the highest-risk item on the replatform"*. It is now
measured rather than feared:

| | |
|---|---|
| Live URLs | 429 |
| Built routes | 578 |
| **Matched** | **426 (99.3%)** |
| Live-only (need a redirect) | **3** |

The three are all WordPress cruft with no editorial value: `/46-2/` (an
auto-generated slug), `/beispiel-seite/` (WordPress's default "Sample Page") and
`/mediathek/` (the media library index).

`node scripts/seo/url-parity.mjs` regenerates `url-parity.json` and a
paste-ready `redirects.nginx.conf`. **The redirects must go in nginx** — Next's
`redirects()` config does nothing under `output: "export"`, because a static
export has no server to run it. This is easy to get wrong and expensive to
discover on launch day.

The 149 built-only routes are the content the previous audit found missing from
the original migration (product-category and product-example pages), plus three
pages added deliberately today.

## 2. Duplicate content — one genuine case found and removed

`/nachhaltigkeit/` and `/unternehmen/qualitaet-umwelt/` shared an identical
title, description **and** H1, and comparison showed **all 15 paragraphs
byte-identical**. They were the same page at two addresses.

Only `/unternehmen/qualitaet-umwelt/` exists on the live site;
`/nachhaltigkeit/` was introduced by the migration, and it had no English
counterpart, so it also broke the DE↔EN pairing. Deleted, and the homepage's
sustainability link repointed at the live URL. No redirect needed — the deleted
address was never public.

Duplicate descriptions site-wide: **1 group → 0**.
One duplicate-title group remains: EN `spring-material` and `spring-material-2`,
which is a duplicate on the live site too. Needs an editorial decision.

## 3. Metadata

`scripts/seo/apply-money-meta.mjs` had not been re-run since the money-page
descriptions were written, so 34 of the most commercially important pages were
still carrying migration-era metadata (`/produkte/druckfedern/` had a 38-character
description that merely restated its title). Re-applied.

**Remaining, and the largest on-page gap: 168 pages whose description simply
repeats the title**, and 226 pages under 1,500 characters. These are the
glossary stubs and news items. This is a copywriting job, not an engineering
one, and it should be prioritised by traffic — which requires Search Console.

> Never hand-edit `seo.title` / `seo.description` in a page file. Edit
> `reference/seo/money-page-meta.json` and re-run `apply-money-meta.mjs`;
> anything typed into a page file directly is overwritten on the next run.

## 4. Verified in-browser

Sampled across page types (homepage, product, careers, both new Resources
pages, an industry page):

- Canonical tag: present on every page
- hreflang: `de`, `en`, `x-default` on every page, reciprocal and self-referencing
- Exactly one H1 per page
- JSON-LD present and parsing: `Organization`, `WebSite`, `BreadcrumbList`,
  `Product`, `Article`, and now `JobPosting`
- **Images missing alt text: 6 → 0**

## 5. AEO / GEO

What was added today:

- **`JobPosting` on all ten vacancies**, making them eligible for Google Jobs —
  a free, high-intent channel Dietz is currently absent from. `datePosted` is
  deliberately omitted: the live site publishes no posting dates, and inventing
  them risks the whole feed. *Real dates would materially improve ranking here.*
- **`/llms.txt`** — a compact, factual description of the company and its money
  pages, in the format AI assistants look for. For a static export this is one
  generated file (`scripts/seo/gen-llms-txt.mjs`).
- **Key takeaways** on product pages: three to five specific, checkable facts in
  the format answer engines lift verbatim. Authored, never generated, and
  `scripts/content/check-takeaways.py` fails the build if a takeaway cites a
  figure or standard the page body does not state.
- **Heading anchors** on every H2, so an answer engine can deep-link a section.

Still open: `sameAs` is absent from the Organization markup because the footer's
social links point at `facebook.com`, `linkedin.com`, `instagram.com` and
`youtube.com` — the platforms, not Dietz's profiles. This is a **live user-facing
bug**, not only a markup gap. Real profile URLs would fix both.

## 7. Still outstanding

1. **Keyword cannibalisation.** 17 DE and 17 EN pages target compression-spring
   terms. **Do not consolidate blind** — without Search Console you would redirect
   away pages that are currently earning impressions.
2. **`postMeta.date` is absent on all 578 pages.** Blog posts render undated,
   `Article` markup carries no `datePublished`, and the sitemap emits no
   `lastmod`. The dates exist in the live WordPress and are recoverable.
3. **168 thin/duplicate descriptions**, as above.
4. **nginx cache headers** for `/frames/` and `/images/`
   (`Cache-Control: public, max-age=31536000, immutable`). 67 MB revalidating on
   every visit outweighs every in-repo optimisation. Deploy-side, not in the repo.
