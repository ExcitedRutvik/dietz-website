## H1: Glossary: Spring mechanisms explained simply
Spring mechanisms describe the different types and applications of springs in technical systems. There are various spring mechanisms, including compression springs, tension springs, torsion springs and leaf springs. Each mechanism has specific properties that are suitable for certain applications. For example, compression springs are used in suspension systems, while extension springs are used in locking mechanisms. Understanding the different spring mechanisms enables engineers to select and design the most suitable spring for each application.
