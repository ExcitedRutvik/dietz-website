# Glossar: Federsteifigkeit einfach erklärt

**Source URL:** https://www.dietz.eu/federsteifigkeit/

## H1: Glossar: Federsteifigkeit einfach erklärt
Die Federsteifigkeit, auch als Federkonstante bekannt, ist ein Maß für die Steifheit einer Feder. Sie gibt an, wie viel Kraft erforderlich ist, um die Feder um eine Einheit zu dehnen oder zu komprimieren. Die Federsteifigkeit wird in Newton pro Meter (N/m) gemessen. Eine höhere Federsteifigkeit bedeutet, dass die Feder steifer ist, während eine niedrigere Steifigkeit auf eine weichere Feder hinweist. Die genaue Kenntnis der Federsteifigkeit ist entscheidend für die Auslegung von Feder-Systemen in verschiedenen Anwendungen, von Fahrzeugfahrwerken bis zu industriellen Maschinen.
